This app is insecure on purpose. It exists so you can try Preflight without needing an app of your own.

Every credential in it is fake and non-functional. The keys are well-formed so a scanner can parse them, but they are signed with a dummy value and point at a project that does not exist. There is no database behind this page and no data to leak.

What a scan of this page should find

  • A Supabase service_role key in the JavaScript — the severe one
  • An AI provider key in the JavaScript
  • A Supabase anon key, which is meant to be public but signals the RLS question
  • Permissive CORS that allows credentials from any origin
  • A published source map reference
  • No Content Security Policy, no HSTS, no frame protection
